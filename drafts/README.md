# 📝 1차 초안 보관소 (`drafts/`)

이 폴더는 **저품질 방지 규칙 제1조(100% 무검수 자동 발행 금지)**에 따라, 정식 발행 전 **1차 초안(한국어 + 영어 마크다운 원고)**을 먼저 생성하여 검토받는 대기 공간입니다.

## 검수 및 발행 3단계 절차
1. 에이전트가 최신 IT/AI 뉴스를 수집해 `drafts/ko/` 및 `drafts/en/`에 1차 초안을 생성합니다.
2. 사용자가 초안을 확인하고 **개인 의견이나 실사용 경험 한두 줄**을 전달합니다.
3. 에이전트가 해당 코멘트를 `editorNote` 및 본문에 자연스럽게 반영한 뒤 `src/content/blog/ko/` 및 `src/content/blog/en/`으로 이동하여 배포합니다.
